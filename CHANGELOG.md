# Changelog

All notable changes to **El-Batta El-Meshmeshia** are documented here.

## 1.1.0 — 2026-08-19

El-Batta now lives in a dedicated activity-bar container with the full-color pixel mascot always visible in a persistent sidebar. Paste violations update an in-panel speech bubble immediately, reveal the panel without stealing editor focus, and expose cleanup, sharing, guard, and statistics controls beside the character. Mixed Arabic and English developer terms now use bidirectional isolation and an explicitly RTL bubble, preventing punctuation and code words from jumping to the wrong visual position. Native warning notifications remain available but are disabled by default because the duck panel is now the primary reaction surface.

## 1.0.0 — 2026-08-19

The first release introduced local suspicious-paste detection for AI artifacts and configurable medium or huge code blocks. Triggered ranges receive a temporary blur, an Egyptian-Arabic roast, and a status-bar countdown. The release also includes one-command AI-junk cleanup, local-only statistics, a guard toggle, rapid-paste timer handling, and the original Fake Senior Duck pixel-art identity.
